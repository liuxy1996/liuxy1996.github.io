异常

异常把正常路径和失败路径分开；捕获、传播、自定义和资源清理都需要明确边界。

11 分钟入门到进阶24 章手册
01

异常模型与捕获

异常是对象，可以携带信息和 cause。try/catch/finally 中 finally 总会执行，适合清理资源。受检异常要求调用者显式处理；运行时异常通常表示编程错误。catch 应该从具体到宽泛。

02

自定义异常与 try-with-resources

自定义异常应该说明业务语义，并在构造函数里保留 cause。try-with-resources 自动关闭实现了 AutoCloseable 的资源，即使 try 块抛出异常也不会漏掉关闭。

TAKEAWAYS

读完这一章

  • 异常让失败路径显式化；保留 cause 才能定位根因。
  • finally 和 try-with-resources 负责资源释放。
  • 自定义异常用于业务语义，不要把所有异常都包成同一种。
