类型信息

Class 对象、instanceof、反射和动态代理让程序在运行时检查与操作类型，也带来额外的耦合。

10 分钟入门到进阶24 章手册
01

Class 对象与类型检测

每个已加载类型都有 Class 对象，可以通过 类名.class、getClass() 或 Class.forName 获得。instanceof 在向下转型前检查类型；Java 16 之后还支持模式匹配，但本书基线是 Java 8。

02

反射与动态代理

反射允许在运行时查找方法并调用，适合框架和插件；代价是失去编译期检查、变慢，并且更难重构。动态代理在接口之上生成包装对象，适合横切逻辑，但不要用它代替清晰的接口设计。

TAKEAWAYS

读完这一章

  • Class 对象描述运行时类型，instanceof 保护向下转型。
  • 反射适合框架，不适合业务代码的日常路径。
  • 动态代理把包装逻辑集中到接口边界。
