01
OBJECTS & LANGUAGE

对象与语言

从对象模型、运算符、控制流一路走到封装、复用、多态、接口与内部类。

01对象的概念先建立对象模型：状态、行为、接口、封装、复用、继承与多态，是后面所有语法的地基。12 分钟02安装 Java 与本书用例准备 JDK，理解 javac 与 java 的分工，跑起一个带包名的示例。7 分钟03万物皆对象引用与对象是两件事。理解 new、字段、方法、作用域和垃圾回收，才能读懂 Java 的内存模型。10 分钟04运算符运算符的优先级、整数除法、类型转换和引用赋值，比记住符号表更值得花时间。9 分钟05控制流if、循环、for-in 与 switch 决定代码按什么顺序执行；顺序本身就是设计的一部分。8 分钟06初始化和清理构造器保证对象可用，初始化顺序决定你看到什么，垃圾回收让清理不再是显式 free。12 分钟07封装把可变状态关进类里，只暴露需要的操作，让包和访问修饰符成为真实的边界。8 分钟08复用组合、继承、委托和 final：复用的四种工具，各自适合不同的关系。11 分钟09多态向上转型之后，调用的方法仍由对象的真实类型决定；这是 Java 动态绑定的核心。11 分钟10接口接口把“能做什么”从“怎么实现”里分离出来；抽象类则适合共享部分实现和状态。10 分钟11内部类内部类持有外部类引用，匿名类适合一次性实现，静态嵌套类则不依赖外部实例。10 分钟
02
COLLECTIONS & FUNCTIONS

容器与函数式

集合、Lambda 与流：Java 8 如何把数据变换写得更可组合。

12集合List、Set、Map、Queue 与 Iterator 组成了 Java 的数据结构层；泛型让集合保持类型安全。13 分钟13函数式编程Lambda 让函数成为值，函数式接口描述函数形状，纯函数与不可变数据让组合变得可靠。13 分钟14流式编程Stream 把集合变换拆成源、中间操作和终止操作，并用惰性求值把计算推迟到真正需要时。14 分钟
03
TYPES & CRAFT

类型与工程

异常、测试、文件、字符串、类型信息、泛型、数组、枚举与注解。

15异常异常把正常路径和失败路径分开；捕获、传播、自定义和资源清理都需要明确边界。11 分钟16代码校验测试、断言、日志、基准与重构：让代码在变化中仍然可信。10 分钟17文件用 Path 与 Files 处理路径、目录、读写和文件树，比起手写流更安全、更清晰。11 分钟18字符串String 不可变，拼接会产生新对象；StringBuilder、格式化和正则让文本处理更可控。10 分钟19类型信息Class 对象、instanceof、反射和动态代理让程序在运行时检查与操作类型，也带来额外的耦合。10 分钟20泛型泛型把类型参数化，在编译期保护集合与算法；擦除、边界和通配符决定了它的能力边界。13 分钟21数组数组长度固定、是对象、会做运行时类型检查；Arrays 工具类覆盖填充、排序、查找和流化。10 分钟22枚举枚举不是整数常量：它是完整的类，可以带字段、方法、接口，并用 EnumSet/EnumMap 获得类型安全集合。9 分钟23注解注解把元数据写进源码，由编译器、框架或注解处理器读取；它本身不会执行任何逻辑。9 分钟

CONCURRENCY

并发

任务、线程池、共享状态、CompletableFuture 与死锁。

24并发编程并发不是“多开线程”：任务是边界，共享状态是风险，线程池、锁和 CompletableFuture 是用来组织边界的工具。15 分钟
