LANGUAGE

语言与类型

JDK、类、接口和泛型，先把 Java 的静态类型世界走一遍。

01JDK、类与第一个程序安装 JDK，写一个能编译运行的类，理解包、入口方法和静态类型。9 分钟02对象、接口与泛型用封装保护状态，用接口表达能力，用泛型让类型关系在编译期成立。12 分钟
02
FUNCTIONAL

函数式 Java

Lambda、Stream、Collector 与 Optional 改变了表达式和数据的写法。

03Lambda 与函数式接口Lambda 不是匿名类的语法糖：它让函数成为可传递的值，也让 Java 的集合操作开始变得可组合。12 分钟04Stream 管道Stream 把“遍历并变换集合”拆成一条可组合的管道，同时保持惰性和不可变性。14 分钟05Collector 与并行流用 Collector 把流收束成 Map、分组或字符串；并行流只有在对的场合才值得用。13 分钟06Optional 与默认方法Optional 让“可能没有”变成返回类型（而不只是 null），默认方法允许接口在不破坏实现者的情况下演化。11 分钟
03
MODERN

时间与异步

不可变时间模型，以及用 CompletableFuture 组合异步任务。

07新的日期与时间 API用不可变的 LocalDate、LocalDateTime、Instant 与 Duration 替代容易出错的 Date 和 Calendar。10 分钟08CompletableFuture 与异步组合把异步任务像 Stream 一样组合起来，同时知道异常、线程池和阻塞边界在哪里。15 分钟
