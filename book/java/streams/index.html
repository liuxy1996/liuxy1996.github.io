Stream 管道

Stream 把“遍历并变换集合”拆成一条可组合的管道，同时保持惰性和不可变性。

14 分钟入门到进阶8 章手册
01

源、中间操作与终止操作

Stream 不存储数据，它从集合、数组或生成器读取数据。中间操作如 filter、map、sorted 返回新的 Stream，终止操作如 collect、forEach、count 才真正触发计算。

一条管道只消费一次。不要把同一个 Stream 保存起来反复使用。

02

flatMap 与 reduce

flatMap 把每个元素映射成 Stream 后再合并，适合处理嵌套列表；reduce 把一串值折叠成一个值。对于整数求和，优先使用 mapToInt(...).sum()，避免不必要的装箱。

03

惰性、短路与副作用

中间操作是惰性的，所以 anyMatch、findFirst 可以在找到结果后停止处理剩余元素。不要在 map 或 filter 里打印、修改集合或做网络请求；Stream 应该描述“计算”，而不是隐藏控制流。

需要索引时，用 IntStream.range 或普通的 for 循环往往更清楚。Stream 不是替代所有循环的命令。

TAKEAWAYS

读完这一章

  • Stream 是惰性的，终止操作才触发计算。
  • flatMap 展开嵌套结构，mapToInt 避免装箱开销。
  • Stream 适合无副作用的变换，不要用它隐藏状态修改。
