Java / CHAPTER 10

接口

接口把“能做什么”从“怎么实现”里分离出来；抽象类则适合共享部分实现和状态。

10 分钟入门到进阶24 章手册
01

抽象类与接口

抽象类可以带字段和已实现的方法，适合一组关系紧密的类型；接口定义能力，一个类可以实现多个。接口字段隐式 public static final，方法在 Java 8 中可以有 default 和 static 实现。

02

解耦、适配与工厂

接口让调用者不需要知道对象的构造过程。工厂方法把“创建哪种实现”的决定留在工厂内部，适配器则把一个已有接口包装成调用者需要的形状。这两者都在降低依赖，而不是增加层数。

TAKEAWAYS

读完这一章

  • 抽象类适合共享实现，接口适合表达能力与解耦。
  • 默认方法与静态方法让接口可以继续演化。
  • 工厂把构造细节移出调用者，适配器连接不兼容的接口。
