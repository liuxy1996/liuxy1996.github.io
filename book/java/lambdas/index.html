Lambda 与函数式接口

Lambda 不是匿名类的语法糖：它让函数成为可传递的值，也让 Java 的集合操作开始变得可组合。

12 分钟入门到进阶8 章手册
01

一个抽象方法就是一个函数类型

函数式接口是只有一个抽象方法的接口。Lambda 会根据目标类型推断参数和返回值。JDK 已经提供了常用的函数类型：Function<T,R>、Predicate<T>、Consumer<T>、Supplier<T>。

02

方法引用让意图更直接

当 Lambda 只是原样调用一个已有方法时，用方法引用更短、更容易读。四种常见形式是 Type::staticMethod、instance::method、Type::instanceMethod 和 Type::new。

03

捕获变量必须有效 final

Lambda 可以读取外部局部变量，但这些变量必须事实上不可变。Java 没有闭包修改局部变量的机制，需要修改状态时，用有一个元素的数组、可变对象或显式设计返回新值。

这看起来受限，但能让并发下的捕获关系更容易分析。优先让函数保持无副作用的纯变换。

TAKEAWAYS

读完这一章

  • 函数式接口 = 一个抽象方法；Lambda 是它的简洁实现。
  • 方法引用适合直接转发给已有方法。
  • Lambda 捕获的局部变量必须有效 final。
