封装

把可变状态关进类里，只暴露需要的操作，让包和访问修饰符成为真实的边界。

8 分钟入门到进阶24 章手册
01

包与访问权限

Java 有四层访问：private、包级默认、protected 和 public。优先让字段私有，把校验放在 setter 或构造器里。包不是装饰，它是代码的组织边界。

02

接口和实现分开

封装不只是 private。调用者依赖 public API，而不是内部集合、字段和临时实现。这样你才能替换数据结构、加入缓存或改变算法，而不破坏外部代码。

类级别的访问权限同样重要：只被同一包使用的辅助类，不需要变成 public。

TAKEAWAYS

读完这一章

  • 字段默认私有；公开的是经过设计的行为。
  • 包级访问是隐藏实现细节的实用工具。
  • 封装的目标是允许实现变化，而不是制造仪式。
