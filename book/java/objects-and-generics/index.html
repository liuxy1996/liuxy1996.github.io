对象、接口与泛型

用封装保护状态，用接口表达能力，用泛型让类型关系在编译期成立。

12 分钟入门到进阶8 章手册
01

让字段私有，让行为公开

类的字段通常声明为 private，通过方法暴露必要的操作。这样做不是仪式，而是把“状态如何变化”集中在一个地方，方便校验、调试和以后修改。

final 字段一旦赋值就不能再改；final 引用也不能指向另一个对象，但对象内部仍可能可变。这两件事要分清。

02

接口描述能力

接口表达“能做什么”，类表达“是什么，以及怎样做”。一个类可以实现多个接口，因此接口是组织可组合能力的主要方式。

Java 8 之前接口只能有抽象方法；Java 8 引入了 default 和 static 方法，后面会单独讨论它们带来的影响。

03

泛型：把类型推迟到调用处

泛型让容器和算法在编译期保留元素类型。Box<T> 里的 T 是类型参数，调用 new Box<>("Rust") 时再推断。使用泛型后，从容器取出的值不再需要强制转换，错误也会更早暴露。

TAKEAWAYS

读完这一章

  • 字段私有、行为公开，让状态变化有唯一入口。
  • 接口描述能力，类可以组合多个接口。
  • 泛型让类型在编译期被保留，减少强制转换。
