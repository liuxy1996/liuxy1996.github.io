PROGRAM DESIGNCHAPTER 07

输入与输出

用 f-string 输出，用 with open() 安全读写文件，用 JSON 在“Python 对象”和“文本”之间来回转换。

约 6 分钟3 个知识点3 段可运行代码
CH.07

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

格式化输出：f-string 优先#

在字符串前加 f，用 {表达式:格式} 插入内容。宽度、对齐、精度、百分比都能直接写在花括号里。

格式含义示例结果
:.2f两位小数3.14
:>8 / :<8右对齐 / 左对齐，宽度 8····abc
:04d整数补零到 4 位0042
:,千位分隔符1,000,000
:.1%百分比，一位小数12.3%

print() 默认自动加换行和空格；用 sep=、end= 控制，例如 print("a", "b", sep="-", end="!") 输出 a-b!。

02

读写文件：永远优先 with#

with open(...) as f 会在代码块结束时自动关闭文件，即使中途异常。文本文件建议显式写 encoding="utf-8"。

坑

用 "w" 打开会立刻清空原文件；不写编码容易在不同系统上产生乱码。二进制文件加 b（如 "rb"），此时读写的是 bytes。

常用模式：r 读、w 覆盖写、a 追加、x 仅当文件不存在时创建、+ 读写。其他方法：readline()、readlines()、seek()、tell()。

03

JSON：保存结构化数据#

json.dump 把对象写入文件，json.load 从文件读回；带 s 的 dumps/loads 操作字符串。

补

JSON 只支持字符串键，以及 dict / list / str / int / float / bool / null。元组会被转成数组，集合和自定义对象不能直接序列化。
