数据结构

选对容器，代码就短一半：列表管顺序，元组管不可变记录，集合管去重与成员判断，字典管键值映射。

约 14 分钟7 个知识点7 段可运行代码
CH.05

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

列表：高频方法与栈 / 队列#

列表方法大多是原地修改，返回值为 None。栈用尾部进出；队列用 deque，因为 list.pop(0) 每次都要挪动所有元素。

方法作用提醒
append(x)末尾追加一个元素返回 None
extend(it)展开可迭代对象并追加不同于 append 追加整体
insert(i, x)在索引 i 前插入复杂度 O(n)
remove(x)按值删除第一个 x找不到会 ValueError
pop([i])删除并返回指定位置元素默认末尾；空列表 IndexError
sort()原地排序返回 None；sorted() 才返回新列表
02

推导式：一行生成新容器#

结构固定为 [表达式 for 变量 in 可迭代对象 if 条件]。把推导式当“快捷方式”，逻辑一复杂就换回普通循环。

记

先写“我要什么”，再写“从哪来”，最后补“筛选条件”。例如：[n * 2 for n in nums if n > 0]。

03

元组与 del#

元组是不可变序列，适合表示“一条记录/一个坐标”。单元素元组必须带逗号；del 按索引或切片删除，也可以删除整个变量名。

04

集合：去重与集合运算#

集合无序、元素唯一，成员检测很快。空集合只能写 set()，因为 {} 创建的是空字典。

集合元素必须可哈希，所以不能放列表；需要“不可变的集合”时用 frozenset。

05

字典：键值映射#

用 d[key] 取不存在的键会抛 KeyError；不确定键是否存在时，用 get() 并给默认值。

补

字典键必须可哈希，但值可以是任意对象。3.7+ 字典保持插入顺序，但这不意味着它是有序集合；需要排序时用 sorted(d)。

06

循环技巧与条件判断#

同时拿索引用 enumerate()；同时遍历多个序列用 zip()；反向用 reversed()；排序用 sorted()。

坑

is 比较对象身份（是否为同一个对象），== 比较值。不要用 is 判断数字或字符串相等；判空统一用 is None。

07

序列比较与真值#

相同类型的序列按“字典序”逐元素比较；混合类型若没有定义比较关系，会直接抛 TypeError。

END OF CHAPTER 05
