使用解释器

解释器怎么启动、脚本怎么运行、参数怎么传。这些内容不涉及复杂语法，却决定你能不能顺利开始。

约 4 分钟3 个知识点1 段可运行代码
CH.02

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

启动解释器与交互模式#

在终端输入 python 通常会进入交互模式。Windows 也可能使用 py；macOS/Linux 常使用 python3。看到 >>> 就说明可以开始输入代码了。

记

交互模式里只需输入 >>> 后面的代码，不要连提示符一起输入。命令不存在时，先试 py 或 python3，不要急着怀疑代码。

02

运行脚本、模块与命令行参数#

python 文件名.py 运行脚本；-c 直接执行一行；-m 把一个模块当脚本运行。脚本参数会以字符串列表的形式放进 sys.argv。

坑

直接访问 sys.argv[1] 前要先检查长度，否则没传参数时会抛 IndexError。另外，python -m 模块 与 python 文件.py 的搜索路径不同，包内相对导入通常更适合用 -m。

03

多行输入与源码编码#

输入 if、while 这类复合语句时，主提示符会变成 ...；再输入一个空行表示代码块结束。源码文件默认使用 UTF-8，所以通常不需要额外写编码声明。

只有使用非 UTF-8 编码时，才需要在文件第一行声明编码；如果第一行是 shebang，就写在第二行。

补

编码声明长这样：# -*- coding: cp1252 -*-。现代 Python 项目几乎总是直接用 UTF-8。若 Windows 终端显示中文乱码，可尝试设置 PYTHONUTF8=1 或使用 Windows Terminal。

END OF CHAPTER 02
