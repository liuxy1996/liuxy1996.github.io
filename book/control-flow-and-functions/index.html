LANGUAGE CORECHAPTER 04

控制流与函数

除了 while，还要掌握分支、遍历、模式匹配，以及 Python 函数最容易被低估的参数系统。

约 12 分钟7 个知识点8 段可运行代码
CH.04

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

分支：if / elif / else#

elif 可以有零个或多个，else 可选；Python 靠缩进划分代码块，不用花括号。

记

缩进通常用 4 个空格。不要在一份代码里混用 Tab 和空格，否则会得到 IndentationError。

02

遍历：for 与 range()#

for 直接遍历可迭代对象中的元素，而不是 C 风格的下标循环。需要数字序列时用 range(start, stop, step)，终点不包含。

range() 是惰性序列，不会一次性生成完整列表；list(range(5)) 才把它展开成 [0, 1, 2, 3, 4]。

03

break / continue / else / pass#

break 跳出最近一层循环；continue 直接进入下一轮；循环的 else 只在“没有执行过 break”时运行。

坑

循环后的 else 不是“循环结束后一定运行”。只要遇到过 break，它就会被跳过——这是 Python 独有的易错点。

04
3.10+

模式匹配：match / case 3.10+#

match 不是 C 的 switch，它更像“解构赋值 + 条件判断”。只执行第一个匹配分支，而且可以把序列、对象的组成部分绑定到变量。

补

还能匹配类实例（如 case Point(x=0, y=y):）、字典（{"x": x}）并嵌套；入门阶段先掌握字面量、或模式、序列解构和 _ 即可。

05

定义函数与返回值#

def 定义函数；函数内第一条字符串是文档字符串。没有显式 return 的函数，返回 None。

参数按“对象引用”传递：函数内对可变对象做原地修改，会影响调用者。想避免副作用，就在函数内新建对象并返回。

06

参数魔法：默认值、关键字、/ 与 *#

默认值只在函数定义时求值一次。用可变对象当默认值是经典陷阱，正确写法是用 None 占位。

坑

*args 收集额外位置参数为元组，**kwargs 收集额外关键字参数为字典；调用时 * 和 ** 反过来用于解包。二者可同时出现，但 *args 必须在 **kwargs 前。

07

Lambda、类型注解与风格#

lambda 适合写一次性的小函数；注解只是“给人看 + 给工具查”的提示，运行时不会强制检查类型。

风

PEP 8 速记：4 空格缩进；函数/变量 snake_case；类名 PascalCase；常量 UPPER_CASE；导入放文件顶部；不要在函数参数默认值里写可变对象。
