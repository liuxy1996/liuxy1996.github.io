PROGRAM DESIGNCHAPTER 09

类

类把“数据 + 行为”包在一起。先分清作用域、类变量与实例变量，再理解继承、迭代器和生成器，对象模型就通了。

约 12 分钟6 个知识点6 段可运行代码
CH.09

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

作用域：LEGB 与 global / nonlocal#

查找变量依次走 Local → Enclosing → Global → Built-in。函数内默认会创建局部变量；要改外层的变量，必须显式声明。

坑

函数里一旦给变量赋值，它默认就是局部变量。同名的全局变量不会自动被修改；忘记 global 往往会得到 UnboundLocalError。

02

类、实例与构造器#

__init__ 初始化实例；self 指向当前实例。实例属性写在 self 上，类属性由所有实例共享。

补

类的“魔术方法”负责协议：__repr__ 调试展示、__len__ 支持 len()、__eq__ 支持 ==、__enter__/__exit__ 支持 with。

03

继承、super() 与 MRO#

子类继承父类的属性和方法，super() 调用父类实现。多继承时按 MRO（方法解析顺序）查找；没有特殊理由时优先组合，而不是层层继承。

Python 没有真正的私有成员：_name 是“不要随便动”的约定，__name 会被名称改写为 _类名__name，仍然可以被访问。

04

迭代器：__iter__ 与 __next__#

可迭代对象能用于 for；迭代器用 __next__ 逐个产出值，结束时抛 StopIteration。for 内部会自动处理这两件事。

05

生成器：用 yield 惰性产出#

函数里出现 yield 就变成生成器。它不会一次算完所有结果，而是一次产出一个，适合大文件、无限流和节省内存。

补

生成器只能遍历一次；遍历结束后再 next() 会抛 StopIteration。需要重复使用结果时，把它转成 list() 或重新创建生成器。

06

加分项：@dataclass 少写样板代码#

“以数据为主”的类，用数据类自动生成构造器、__repr__ 和相等比较，比手写更清楚。
