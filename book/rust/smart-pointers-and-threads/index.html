Rust / CHAPTER 08

智能指针与并发

Box 把数据放到堆上，Rc 允许共享所有权，Arc 与 Mutex 把共享带到多个线程。

13 分钟入门到进阶10 章手册
01

Box、Rc 与 RefCell

Box<T> 提供堆分配和固定大小；递归类型必须通过间接层确定大小。Rc<T> 提供单线程内的共享所有权，计数归零时释放。RefCell<T> 把借用检查从编译期推迟到运行期，适合明确的内部可变性场景。

02

线程与共享状态

thread::spawn 创建线程，move 闭包把所需数据移入线程。Arc<Mutex<T>> 是跨线程共享可变状态的常见组合：Arc 负责共享所有权，Mutex 保证同一时刻只有一个线程修改数据。

锁的作用域越短越好。持有锁期间做 I/O 或调用未知代码，容易把速度问题变成等待问题。

03

Send 与 Sync

Rust 用两个标记 trait 描述线程安全：Send 表示值可以移动到另一个线程，Sync 表示引用可以安全地跨线程共享。大多数类型自动实现；Rc 不是线程安全的，所以跨线程共享用 Arc。

并发设计的重点不是“能不能编译”，而是“临界区是否足够小、是否真的需要共享”。

TAKEAWAYS

读完这一章

  • Box 解决递归类型和堆分配，Rc 提供单线程共享。
  • Arc + Mutex 是跨线程共享可变状态的基础组合。
  • 缩短锁的持有时间，比增加更多锁更重要。
