变量、类型与控制流

变量默认不可变；类型通常可以由编译器推导。用 if、loop、while 和 for 表达控制流。

12 分钟入门到进阶10 章手册
01

不可变是默认值

Rust 的 let 默认创建不可变变量。需要修改时加 mut，这会让“这里会发生状态变化”在类型层面变得显眼。

遮蔽（shadowing）是另一个概念：用新的 let 绑定同名变量，旧值被遮住，但变量可以被赋予不同类型。

02

标量类型与复合类型

常用标量类型有整数 i32/u64、浮点 f64、布尔 bool、字符 char。复合类型常见的是元组与数组：元组允许元素类型不同，数组要求长度和类型固定。

类型推断不是魔法。边界不清楚时，显式标注能让编译器更早帮你检查。

03

控制流也是表达式

if、match、块都可以产生值。循环支持 loop、while 和 for；遍历集合时优先用 for，它不需要手动管理索引。

TAKEAWAYS

读完这一章

  • 默认不可变；需要改变时才写 mut。
  • shadowing 允许同名新绑定，也允许改变类型。
  • if 和块是表达式，for 是遍历集合的首选。
