工具链与第一个程序

安装 rustup，认识 Cargo 的目录结构，然后编译并运行第一个 Rust 程序。

9 分钟入门到进阶10 章手册
01

一次装好工具链

Rust 的官方安装器是 rustup。它同时管理编译器 rustc、包管理与构建工具 cargo、格式化工具 rustfmt 和静态检查工具 clippy。

安装完成后，先在终端确认版本：

02

用 Cargo 创建项目

cargo new 会生成一个可执行 crate：Cargo.toml 描述项目与依赖，src/main.rs 是程序入口。

Rust 源文件以 .rs 结尾。入口函数固定叫 main；表达式末尾的分号表示丢弃返回值，而 println! 是宏，末尾带感叹号。

03

日常使用的四个命令

  • cargo check：只做类型检查，不生成最终二进制，速度最快。
  • cargo build：编译到 target/debug/。
  • cargo run：编译并运行。
  • cargo build --release：开启优化，用于交付。

从今天开始，尽量让 Cargo 管理所有构建，而不是直接调用 rustc。

TAKEAWAYS

读完这一章

  • rustup 管理工具链，cargo 管理项目生命周期。
  • 程序入口是 fn main；println! 是宏而不是普通函数。
  • 先把 cargo check / run / build --release 养成习惯。
