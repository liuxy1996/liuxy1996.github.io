Rust系统、所有权与并发

目录

10 章 · 约 2 小时 7 分钟
01
FOUNDATION

语言基础

工具链、类型、控制流，以及 Rust 最核心的所有权模型。

01工具链与第一个程序安装 rustup，认识 Cargo 的目录结构，然后编译并运行第一个 Rust 程序。9 分钟02变量、类型与控制流变量默认不可变；类型通常可以由编译器推导。用 if、loop、while 和 for 表达控制流。12 分钟03所有权与借用谁拥有数据、谁可以借用、借用持续多久。理解这三件事，就理解了 Rust 的核心约束。14 分钟04结构体、枚举与模式匹配用结构体给数据命名，用枚举表达“几种可能”，再用 match 把所有分支处理完整。13 分钟
02
ABSTRACTION

抽象与组织

用模块、集合、错误处理、泛型和 trait 组织真正的程序。

05模块、包与错误处理用 crate 和模块组织边界，用 Result 把可恢复错误交给调用者，用 panic 处理真正的程序错误。12 分钟06集合、闭包与迭代器Vec、String、HashMap 是日常最常用的集合；闭包和迭代器让数据变换保持组合性。13 分钟07泛型、trait 与生命周期用泛型消除重复，用 trait 描述共享行为，用生命周期标注引用之间的关系。14 分钟
03
SYSTEMS

系统与项目

智能指针、并发、测试，以及把知识收束成一个命令行工具。

08智能指针与并发Box 把数据放到堆上，Rc 允许共享所有权，Arc 与 Mutex 把共享带到多个线程。13 分钟09测试、文档与发布把边界写进测试，用 clippy 和 rustfmt 守住一致性，再用文档与示例说明公共接口。11 分钟10最终项目：命令行检索工具把参数、文件读取、错误传播和输出组合起来，写一个类似 grep 的小工具。16 分钟
