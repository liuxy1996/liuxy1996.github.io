PROGRAM DESIGNCHAPTER 06

模块

一个 .py 文件就是模块。把代码拆小、复用，并用 if __name__ == "__main__" 区分“被导入”和“直接运行”。

约 5 分钟3 个知识点3 段可运行代码
CH.06

读法建议：先读说明，再把代码修改一行运行。看不懂的细节可以先跳过， 后面章节会重新遇到它。

01

导入模块的几种方式#

import 模块 导入整个模块；from 模块 import 名字 只拿需要的名字。优先用前两种，避免 from module import *。

补

导入模块时，模块顶层代码会执行一次；之后再用同一模块会直接取自缓存，不会重复执行。导入副作用也应尽量少。

02

作为脚本运行：__name__#

直接运行文件时，__name__ 的值是 "__main__"；被别的文件导入时，值是模块名。这个判断是 Python 脚本的标准入口写法。

记

模块名由文件名决定（my_tool.py → import my_tool）。不要把模块命名为 random.py、json.py 等标准库名，否则可能覆盖真正的标准库模块。

03

模块搜索路径与包#

解释器按 sys.path 找模块，通常包括当前目录、标准库目录和第三方库目录。包含 __init__.py 的目录可以作为“包”，用点号分层导入。

首次导入后会出现 __pycache__/ 和 .pyc 文件，这是字节码缓存，可以安全删除。python -m pkg.module 以模块方式运行，会让包内相对导入更可靠。
