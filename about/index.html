ABOUT / A SMALL PROJECT

一个很小的项目，
想认真陪你学完。

这里不是一所学校，也不是一个考试产品。它只是一份被重新编排过的 Python 学习材料，加上一点让代码真的跑起来的工具。

THE IDEA缓慢、清晰、可以重复。

这个项目从一个很具体的问题开始：官方教程很完整，但第一次学 Python 的人，往往不知道该怎样把那些章节串起来。读完了，却不知道自己到底会了什么。

于是有了这间「自习室」：把第 1 到 16 章重新组织成一条路线，把概念压缩到可以读完的长度，把代码保留成可以运行的样子。 你不需要先配置环境，也不需要先决定要成为工程师。

学习播客是另一条线索。不是把书念一遍，而是把某一章里最难解释的部分， 换成适合散步、通勤和做家务时听的语言。音频会在准备好之后上线， 目前先留下一篇发刊词。

先成为一个能读懂代码的人，再让工具替你加速。
PRINCIPLES

这个站点坚持的几件小事

不是功能越多越好，而是让每一次打开都更接近「学会」。

01

内容优先

16 章、59 个知识点，约 1 小时 39 分钟。每一段示例都为解释概念服务。

02

本地优先

没有账户系统。阅读进度保存在浏览器的 localStorage 里，代码在 Web Worker 中执行。我们不需要收集你是谁。

03

保持可维护

不依赖数据库，不依赖运行时服务器。静态站点可以长期存在， 也方便你 fork 后改成自己的学习笔记。
