关于自习室

一个静态的个人学习书库。把正在学的语言、智能与工程整理成可以阅读、可以运行、 也可以长期维护的页面。

自习室从 Python 开始。现在书库里有三册可以读的手册：Python 16 章， Rust 10 章，以及按 Bruce Eckel《On Java 8》目录整理的中文导读 24 章。

接下来是 AI Agent 和工程手记。每本书都围绕真实问题整理，写清楚它为什么成立、 有哪些代价，以及下次怎样继续往前走。《On Java 8》是事实上的《Java 编程思想》 第五版；本册是导读与练习，不替代原书。

声音栏目是另一条线索：不追工具新闻，也不做成功学，只留下那些过一阵子仍然值得重听的问题。

01内容

三本手册已经上架；AI 后端工程实验室同步记录 FastAPI、RAG 与 Agent 服务。

02实验

从流式接口、模型网关、RAG 到可观测 Agent，每个阶段都要求可运行、可评测。

Next.js 静态导出；Python 在浏览器本地运行。Rust / Java 只有点击在线运行时才发送到外部编译器。
