ABOUT / A SMALL PROJECT

一个长期生长的项目，
想认真陪你学下去。

这里没有课程表，也不是一个考试产品。它是一间持续生长的自习室： 有可以运行的教程，有写下来的思考，也会慢慢出现 AI、Rust、项目案例与一档播客。

THE IDEA缓慢、清晰、可以重复。

这个项目从一个很具体的问题开始：官方教程很完整，但第一次学 Python 的人，往往不知道该怎样把那些章节串起来。读完了，却不知道自己到底会了什么。

于是有了这间「自习室」：先把第 1 到 16 章重新组织成一条路线，把概念压缩到可以读完的长度，把代码保留成可以运行的样子。 但这不是终点。AI Agent、Rust、工程案例和在线简历会陆续加入， 让这里从一本 Python 手册，长成一个真正属于自己的学习档案。

博客用来记录判断，播客用来把判断讲给自己听。它们不追热点，也不制造「学完就能改变人生」的幻觉。 更想留下的是：一个问题怎样被理解，一个选择为什么成立，以及我们怎样把普通的日子积累成能力。

先成为一个能读懂代码的人，再让工具替你加速。
PRINCIPLES

这个站点坚持的几件小事

不是功能越多越好，而是让每一次打开都更接近「学会」。

01

理解优先

16 章、59 个知识点，约 1 小时 39 分钟。每一段示例都为解释概念服务， 而不是为了把页面填满。

02

本地优先

没有账户系统。阅读进度保存在浏览器的 localStorage 里，代码在 Web Worker 中执行。我们不需要收集你是谁。

03

持续生长
